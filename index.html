Planetary GEO AI2026 · AGU abstract submitted

Automated Detection of New Slope Streaks on Mars

Developing and evaluating an image-processing pipeline for candidate Martian slope-streak detection using high-resolution orbital imagery. The workflow combines grayscale normalization, CLAHE, adaptive thresholding, contour filtering, annotation review, and oriented bounding-box exports.

Role
Undergraduate computational geoscientist
Evidence
79 tiles processed; 38,576 accepted candidate contours in an early pipeline run
Output
